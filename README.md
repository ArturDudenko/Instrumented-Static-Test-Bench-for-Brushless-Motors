# Hardware Files – Instrumented Static Test Bench for Brushless Motors

This repository contains the hardware files related to the developed instrumented static test bench for brushless motors.

## Repository Contents

The repository currently includes only hardware design files, namely:

- **SolidWorks part files** (`.SLDPRT`)
- **SolidWorks assembly files** (`.SLDASM`)
- **STEP files** (`.STEP`)

These files correspond to the mechanical design of the test bench structure and its components.

## Purpose

The purpose of sharing these files is to improve the reproducibility of the proposed low-cost test bench and to allow other researchers to analyze, adapt, and further develop the mechanical design.

## Software Availability

The measurement, acquisition, and processing codes used in this work have not yet been made publicly available.

These software files are currently undergoing improvements and refinement before public release.

Therefore, at this stage, this repository provides only the hardware design files.

## Notes

The files available in this repository represent the hardware version used in the reported study. Minor adjustments may still be necessary depending on manufacturing conditions, component availability, and specific experimental requirements.
